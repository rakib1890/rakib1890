## Featured Projects

### 1. RAG Email Support Agent
n8n workflow that retrieves the four most relevant passages from a Supabase pgvector knowledge base (Gemini embeddings) for each unread support email and drafts a reply. The reply is sent only after human approval. A separate Google Drive ingestion workflow keeps the knowledge base updated. Tested end to end.
Stack: n8n, Supabase, pgvector, Gemini, Gmail, Google Drive

### 2. Contract Clause Risk Flagger
Webhook API that takes contract text and runs text extraction, language detection and translation, clause splitting, per-clause LLM rating (Groq) and risk scoring. It writes an HTML report to Google Drive, keeps an audit log, returns a JSON response and sends a Gmail alert for high-risk results.
Stack: n8n, Groq, Google Drive, Gmail

### 3. AI Travel Assistant (MCP)
MCP server with five tools (weather, hotels, restaurants, attractions, currency) and an AI agent (Groq, Llama 4 Scout) with conversation memory. Tool-retry loops were fixed through system-prompt rules.
Stack:n8n, MCP, Groq

### 4. AI Voice Receptionist
